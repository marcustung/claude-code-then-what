# 這份分析包的來源與範圍

這是 Codex 為 Day 9 備稿建立的新教學分析包，非當時完整 repo，也非作者親手執行的歷史工作。
- src 與 tests 從共同訂單服務 git 885e521 取出，代表修改前 v1。
- rules-v2.md 為後續教學需求，BR-03 改為提出退款要求，BR-04 補完重複取消；文件內的 Owner 為教學角色，不是使用者本次替公司核准退款。
- 通知契約與 decisions-v2.1.md 是較晚提出的文件，其提到 v2 七個測試等紀錄不是這份 v1 快照的狀態。這些文件放在包內用來辨識範圍與文件衝突，不代表納入本次 domain 修改。
- 這份包只含指定材料，不能從未提供 API 或呼叫端，推論完整 repo 沒有那些實作。
- 本次 model runner 不執行測試；看到三條測試只代表測試定義存在，不代表在本次已跑過。
- 已讀到程式有函式，不代表知道 repo 所有 caller；找不到時應標未提供。
- 請依 manifest.json 核對檔案来源。不要因資料包不完整而自行宣稱需求已接受，或創造一個必須存在的決策檔名。
