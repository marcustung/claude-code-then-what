Looking at the test results and code:

**Analysis:**
- **SC-03 fails**: "已付款取消要提出退款要求" (Already paid, cancellation should request refund)
- Current code always returns `RefundRequested: false` (line 21)
- Test expects: when `Paid=true` and `Shipped=false` and `Cancelled=false`, should return `RefundRequested=true`

**Required fix:**
1. SC-03 reveals that `RefundRequested` must be determined by whether the order was already `Paid`
2. SC-06 and SC-07 show already-cancelled orders should return as-is with no refund request (don't retry)
3. The spec v2 change mentioned in test comment (line 30) confirms this: `RefundRequested` should be `true` when `Paid=true`

The implementation needs to:
- Check if order is already cancelled → return as-is, no refund
- Check if order is shipped → return as-is, no refund  
- Otherwise cancel it → set `RefundRequested = order.Paid`
