這是本機教學用的 Grafana（只有本機，不是公司環境）。只讀寫目前目錄，不要讀父目錄。

previous-version.json 是你建的 Dashboard 目前版本（UID day25-work-view-v3，資料夾 day25）。使用者驗收意見：
**這張 Dashboard 想回答什麼問題，會貫穿全部。** 標題要直接寫成那個問題，而且是完整的問句；目前的標題「取消訂單通知：然後呢？要處理什麼、交給誰」還不是一個完整問句。下面每一層的標題，都要是從這個問題拆出來的子問題。

請只改標題與各層、各面板的標題文字，其他設計、查詢、用詞（批、對方）都不要動。UID 不變，更新同一個 Dashboard。

環境限制：允許清單一次只認一個 gcx 指令，不要用 ;、&&、| 把多個指令串在一起，否則整串會被擋下。

更新後用 gcx 讀回 Dashboard 確認標題，把最後的定義存成 dashboard.json。最後用繁體中文列出：主標題的問句，以及每一層對應的子問題。
