# 實驗 2：告警調整

每天由外層（不在本 repo）產生當天的指標並評分：
1. 當天指標放在 `ops/data/dayNN/metrics.json`。
2. 用 main 上目前的 `ops/alerts/rules.yml` 評分，成績單放在 `ops/scores/dayNN.json`：page 級雜訊、ticket 級雜訊、每條規則的觸發／有效／雜訊、漏報了哪種事故（只有種類，沒有時間窗）。
3. 迴圈只能看**已經過去的日子**的指標與成績單，提案修改 `rules.yml`；人核准合併後才生效，隔天以新的一天評分。
4. 排程對照組：每天看成績單、出摘要，不改規則。

不可修改：`ops/data/`、`ops/scores/`（由外層寫入）。出題與評分程式、事故答案都不在本 repo（2026-10-05 移出：原本放在 `ops/sim/`，讀得到原始碼就算得出未來的事故）。
起點規則：每天約 390–410 次 page 雜訊；有 silent_drop 的日子會漏報。
