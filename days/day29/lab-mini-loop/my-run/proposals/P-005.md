# P-005｜HighLatency 與 AnyServerError 加 for_minutes 2，濾掉單分鐘孤立尖峰

- 第 2 天觀測產出，等 Gate 1 裁決

【改動】rules.yml 中 HighLatency：for_minutes 由 0 改為 2；AnyServerError：for_minutes 由 0 改為 2。threshold 與 severity 不變。

【預期】兩條規則合計每日 page 雜訊由約 45 次（23+22）降到個位數，整體 page 雜訊再下降約 10%。

【證據】第 2 天 AnyServerError 觸發 22 次且全是孤立的單分鐘（error_rate=1.0）、有效 0 次；HighLatency 觸發 23 次、有效 0 次，其中 22 段只有 1 分鐘。第 1 天分別是 13 次和 22 次，同樣有效 0 次。風險：若未來出現只持續 1 分鐘的真事故，這兩條規則會晚 1 分鐘才 page。兩天的資料中沒有這種案例，審核時可決定是否接受；若想保守，可以只採用第一張提案，也已足以達標。
